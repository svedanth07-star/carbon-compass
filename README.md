# 🌱 Carbon Compass

### Track your footprint. Understand your impact. Make greener choices.

Carbon Compass is a full-stack application designed to help users understand their environmental impact, track their carbon footprint, and explore personalized sustainability recommendations.

## ✨ Features

* 🌍 Carbon footprint tracking
* 📊 Category-wise emissions analysis
* 📈 Interactive dashboard and visualizations
* 🤖 AI-powered climate recommendations
* 🎯 Carbon reduction goal simulator
* 📅 Historical footprint tracking
* 🔐 User authentication

## 🛠️ Tech Stack

* **Frontend:** React, TypeScript, Vite
* **Backend:** Node.js, Express
* **API:** tRPC
* **Database:** MySQL
* **ORM:** Drizzle ORM
* **UI:** Tailwind CSS, Radix UI
* **Charts:** Recharts
* **Testing:** Vitest

## 📁 Project Structure

## 🚀 Getting Started

### Prerequisites

* Node.js
* pnpm
* MySQL

### Installation

Clone the repository:

```bash
git clone https://github.com/svedanth07-star/carbon-compass.git
cd carbon-compass
```

Install dependencies:

```bash
pnpm install
```

Configure the environment variables required by the application. Keep API keys, database credentials, and other secrets private.

Start the development server:

```bash
pnpm dev
```

Other useful commands:

```bash
pnpm check
pnpm test
pnpm build
```

## 🌍 Project Goal

Carbon Compass explores how technology and data can help people understand their environmental impact and make more sustainable everyday choices.

## 🔒 Disclaimer

Carbon footprint calculations are estimates and depend on the emission factors, assumptions, and information provided to the application.
